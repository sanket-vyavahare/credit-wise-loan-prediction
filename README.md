## 📌 About The Project

**Credit Wise** is a Machine Learning project designed to analyze applicant financial information and predict whether a loan application will be approved or rejected.

The project focuses on data preprocessing, exploratory data analysis, feature engineering, and classification algorithms to understand loan approval patterns.

## 🎯 Project Objectives

- Analyze loan applicant data.
- Handle missing values.
- Identify important patterns using EDA.
- Apply feature encoding and scaling.
- Train multiple Machine Learning models.
- Evaluate model performance.

## 📊 Model Evaluation

The models are evaluated using:

- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix

**Best Model:** Gaussian Naive Bayes (based on Precision in the initial model comparison).

## 💻 Installation & Usage

**Step 1: Clone the repository**

```bash
git clone https://github.com/YOUR-USERNAME/credit-wise-loan-prediction.git
```

**Step 2: Navigate to project folder**

```bash
cd credit-wise-loan-prediction
```

**Step 3: Install dependencies**

```bash
pip install -r requirements.txt
```

**Step 4: Run Jupyter Notebook**

```bash
jupyter notebook
```

Open `credit_wise.ipynb` and run all cells.
